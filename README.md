# Кастомный список с маркерами

Простой и стильный список с кастомными маркерами, созданный с использованием современных CSS-возможностей.

## Особенности

- Кастомные маркеры списка (✓)
- Анимация при наведении
- Адаптивный дизайн
- Градиентный фон
- БЭМ методология

## Технологии

- HTML5
- CSS3
- БЭМ

## Установка

1. Клонируйте репозиторий
2. Откройте index.html в браузере

counters/
